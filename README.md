# H2Life

Статическая визитка о водородных технологиях для автомобилей. Один `index.html`: стили, фотографии и схема встроены в файл. Внешних шрифтов, трекеров, библиотек и запросов для загрузки картинок нет. Навигация и FAQ работают без JavaScript.

## Установка на настроенный VPS

```bash
curl -fL https://raw.githubusercontent.com/lifelover2b/h2life/main/deploy.sh -o /tmp/h2life-deploy.sh
sudo bash /tmp/h2life-deploy.sh
curl -I https://h2life.tech
```

Установщик скачивает страницу, проверяет HTML и название, сохраняет существующий `index.html` в `/var/backups/h2life/`, затем атомарно заменяет `/var/www/html/index.html`. Конфигурация прокси и веб-сервера не изменяется. Страница обслуживается настроенным ранее локальным origin Nginx на 127.0.0.1:18081. Перезапуск Telemt не нужен.

Для установки конкретного коммита передайте его SHA:

```bash
sudo env H2LIFE_REF=COMMIT_SHA bash /tmp/h2life-deploy.sh
```

Проверены ссылки на разделы, встроенные изображения, отсутствие внешних загрузок, UTF-8 и синтаксис установщика. Визуальная проверка в браузере в текущей среде недоступна; внешний вид следует проверить после размещения.
